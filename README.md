## ✨ Funcionalidades

- 🔢 Definição da quantidade de números a sortear
- 📏 Definição do intervalo (valor mínimo e máximo)
- 🎯 Sorteio de números aleatórios
- [🚫 Opção de não repetir números]
- [🔄 Botão para reiniciar o sorteio]
- [⚠️ Validação dos campos, como intervalo inválido]

## 🛠️ Tecnologias

| Tecnologia | Uso |
|------------|-----|
| **HTML5** | Estrutura da página |
| **CSS3** | Estilização e layout |
| **JavaScript** | Lógica do sorteio e manipulação do DOM |

## 📁 Estrutura do projeto

```
projeto-sorteador-numeros/
├── index.html   # Estrutura da página
├── style.css    # Estilos da aplicação
└── script.js    # Lógica do sorteio
```

## 🧠 O que aprendi

- Selecionar e manipular elementos do DOM
- Trabalhar com eventos de clique e leitura de inputs
- Gerar números aleatórios com `Math.random()`
- Validar entradas do usuário
